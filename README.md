# QinetiQ Valuation and Strategic Alternatives Analysis

Independent investment-banking project analysing QinetiQ Group plc, its intrinsic valuation, and the strategic options available for its US business.

## Central question

What is QinetiQ worth, and should management retain, restructure, or divest its US operation?

## Conclusion

The core valuation range is **£5.29–£5.52 per share**, with an illustrative central value of **£5.40**. The recommended strategy is to continue improving the US operation while maintaining a competitive sale process.

A disposal near **1.00x revenue** does not create value relative to the retain case. Approximately **1.13x** is mathematical break-even, while at least **1.25x** and preferably closer to **1.50x** provides a more credible buffer for transaction and execution risk.
